# Sri Ram Khandelwal Portfolio

A simple static portfolio hosted with GitHub Pages at `ram2408.github.io`.

## Overview

The site is a lightweight one-page portfolio built with plain HTML, CSS, Bootstrap's bundled responsive navbar behavior, and Font Awesome icons. It highlights:

- Professional experience
- Selected projects
- Skills
- Education and achievements
- Contact and social links

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static file server.

## Main files

- `index.html` - page content and structure
- `css/resume.css` - custom portfolio styling
- `img/` - profile and site images
- `vendor/` - vendored Bootstrap, jQuery, and Font Awesome assets
